# 개발 제품 명세 v1.0

## 1. 제품 정의

시하 AI 영어친구는 영어 단어와 짧은 표현을 어느 정도 이해하지만 스스로 문장을 만들기 어려운 6~8세 아동을 위한 음성 대화 서비스다. 아이가 이미 아는 영어를 짧게 반복 사용하며 발화 성공 경험을 쌓게 한다.

교육 앱보다 영어로 반응하는 놀이 친구에 가깝게 느껴져야 한다.

## 2. 해결할 문제

| 문제 | 제품 요구사항 |
|---|---|
| AI 표현이 갑자기 어려워짐 | 강한 Realtime instruction과 사후 위반 분석으로 반복 문제를 보완한다. |
| 아이가 단답만 함 | 적절한 간격으로 모델링·문장 시작·선택적 따라 말하기를 사용한다. |
| 아이가 이해하지 못함 | 한국어 힌트, 그림 선택지, 더 쉬운 질문 순으로 지원한다. |
| AI가 아이 말을 오인식함 | 확신이 없으면 단정하지 않고 확인은 최대 한 번만 하도록 지시한다. |
| 대화가 끊김 | 정상 턴은 다음 아이 발화를 초대한다. |
| 질문이 연속되어 취조처럼 느낌 | 질문 외에 문장 완성, 선택, 행동 요청, 반응 대기를 섞는다. |

## 3. 성공 기준

### North-star outcome

아이의 발화 횟수를 유지하면서 도움 없이 사용한 영어 표현이 늘고, 도움 요청과 중단률이 높아지지 않는다.

### MVP 측정 지표

| 분류 | 지표 | 파일럿 관찰 목표 |
|---|---|---|
| 활성도 | Child turns | 5분 12~25회, 8분 20~35회 |
| 활성도 | Response rate | 75% 이상 |
| 지속 | 5분 완료율 | 80% 이상 |
| 영어 사용 | English 또는 Mixed turns | Child turns의 60% 이상 |
| 확장 | Short sentence turns | 세션 3회 이상 |
| 자발성 | Spontaneous pattern uses | 세션 1회 이상부터 관찰 |
| 부담 | Help rate | 유도 턴의 25% 이하 |
| 부담 | Repair rate | 유도 턴의 10% 이하 |
| 부담 | Refusal/stop rate | 추세 관찰, 목표치는 파일럿 후 설정 |

영어 발화 분류는 `ENGLISH`, `MIXED`, `KOREAN`, `UNCLEAR`, `SILENCE`로 고정한다. `I like 딸기`는 `MIXED`다.

## 4. MVP 사용자

### Child

- 6~8세
- 영어 영상, 책, 학원 등 노출 경험이 있음
- `cat`, `pink`, `cookie` 같은 단어는 알 수 있음
- `I like cats`를 따라 할 수 있지만 자발 생성은 어려울 수 있음

### Parent

- 진도보다 아이가 영어에 거부감 없이 입을 여는 것을 원함
- 발화량, 자발적 표현, 도움이 필요했던 부분의 변화를 보고 싶어 함

## 5. 범위

### 포함

- 부모 온보딩
- 5분 기본 세션, 반응이 좋을 때 최대 8분 연장
- OpenAI Realtime speech-to-speech와 브라우저 WebRTC 직접 연결
- 서버 Session Director와 선택적 sideband 제어
- 그림 선택지와 의미 기반 캐릭터 반응
- 세션 리포트, 선택적 transcript
- 아동별 단어·패턴 사용 이력

### 제외

- 발음·문법 점수
- 시험, 숙제, 순위
- 자유 주제 프리토킹
- 긴 역할극과 복잡한 게임
- 교사가 편집하는 커리큘럼 도구
- 실시간 카메라 분석

## 6. 세션 구조

| 단계 | 시간 | 목적 |
|---|---:|---|
| Hello | 20~30초 | 이름을 부르고 아주 쉬운 반응 유도 |
| Warm-up | 45~60초 | 오늘의 입력·출력·지원 수준 추정 |
| Core loop A | 1.5~2분 | 주제 1과 Pattern A 사용 |
| Play reaction | 30~60초 | 발화가 화면을 변화시키는 경험 |
| Core loop B | 1.5~2분 | 주제 2에서 Pattern A 재사용, Pattern B 노출 |
| Recall | 30~60초 | 초반 표현을 다른 맥락에서 회수 |
| Wrap-up | 20~30초 | 평가 없이 긍정적으로 종료 |

기본 종료 시점은 5분이다. 아이가 `STOP_REQUESTED`가 아니고 상태가 `ACTIVE`이면 `More?`를 한 번 물어 최대 8분까지 연장한다.

## 7. 난이도 모델

프로필은 세 축으로 유지하지만 매 턴 자체 Controller가 강제로 조정하지 않는다. 세션 시작 instruction과 다음 세션 계획에 반영한다.

### Input level

| 값 | AI 발화 |
|---:|---|
| 1 | 1~4단어, Yes/No 또는 명사 선택 |
| 2 | 3~6단어, 익숙한 의문문 |
| 3 | 4~7단어, 익숙한 패턴과 수식어 1개 |

### Output level

| 값 | 기대 답변 |
|---:|---|
| 1 | Yes/No 또는 한 단어 |
| 2 | 2~4단어 청크 |
| 3 | 3~7단어 짧은 문장 |

### Support level

| 값 | 지원 |
|---:|---|
| 0 | 음성만 |
| 1 | 영어 텍스트 또는 시각 단서 |
| 2 | 그림 선택지 2개 |
| 3 | 한국어 힌트 + 그림 선택지 |

한국어로 의미상 적절하게 답하면 comprehension은 성공으로 처리하고 output 또는 support만 조정한다.

## 8. 목표 표현

세션당 최대 2개다. Pattern A는 반복 사용하고 Pattern B는 가볍게 노출한다.

- `I like ___`
- `It's ___`
- `I want ___`
- `Yes, I do`
- `No, I don't`

따라 말하기 제안은 세션당 최대 3회, 연속 사용 금지, 거절 후 같은 세션에서 최소 5턴 동안 재요청 금지다.

## 9. 콘텐츠

MVP는 5개 주제, 80~150개 핵심 단어로 시작한다.

| 주제 | 핵심 분기 |
|---|---|
| Animals | 종류, 색, 크기, 귀여움, 움직임 |
| Colors | 좋아함, 사물 색 변경, 두 색 선택 |
| Food | 좋아함, 원함, 맛, 간식 선택 |
| Toys | 종류, 색, 크기, 가지고 싶음 |
| Today | 기분, 날씨, 옷, 오늘 한 일의 매우 제한된 선택 |

모든 콘텐츠 항목은 `core_words`, `prompt_templates`, `choice_options`, `visual_effect`, `allowed_patterns`를 가진다.

## 10. 안전 및 개인정보

- 주소, 전화번호, 학교 위치, 계정 정보를 묻지 않는다.
- 성적·폭력적·위험 행동 주제로 확장하지 않는다.
- 위기 또는 학대 가능성이 있는 발화는 안전 이벤트로 분류하고, 아이에게 조사성 질문을 이어가지 않으며 부모용 안전 정책에 따라 처리한다.
- AI는 사람이라고 주장하거나 비밀을 요구하지 않는다.
- 원본 음성 보관은 별도 부모 동의가 있을 때만 가능하다.
- transcript·원본 음성 삭제 기능을 제공한다.
- 아동 데이터를 모델 학습에 사용하는 동의는 서비스 이용 동의와 분리한다.

## 11. 비기능 요구사항

- 아이 발화 종료부터 첫 응답 음성 재생까지 파일럿 목표 P50 1초 안팎, P95 2초 이하
- 브라우저와 OpenAI 사이 오디오는 애플리케이션 서버를 중계하지 않음
- semantic VAD의 `low`와 `auto`를 실제 아동 발화로 비교
- 모든 자동 판정은 confidence와 근거 코드를 저장
- 네트워크 실패 시 아이에게 기술 오류를 설명하지 않고 짧게 종료 또는 재시도
- 모바일 우선, 큰 터치 영역, 읽기를 요구하지 않는 UX

## 12. 출시 기준

- 7개 필수 대화 시나리오 자동 테스트 통과
- transcript 평가에서 과도한 문장·질문·반복·주제 이탈을 자동 표기
- 불확실 발화 확인 요청 1회 제한 준수
- 중단 의사 표현 후 추가 학습 유도 없음
- 내부 파일럿 20세션에서 치명적 대화 중단 오류 0건
