# 화면 및 UX 명세 v1.0

## 1. 공통 원칙

- 음성이 중심이고 텍스트는 보조다.
- 아이 화면에는 점수, 레벨, 진도율을 표시하지 않는다.
- 한 화면의 주요 행동은 하나다.
- 터치 선택지는 항상 2개 이하, 큰 이미지와 음성 레이블을 사용한다.
- 마이크 상태를 색만으로 표현하지 않는다.
- 아이의 영어가 화면을 의미 있게 바꿔야 한다.

## 2. Home

필수 요소:

- 중앙 캐릭터
- `시하야, 영어 친구 만나볼까?`
- `이야기 시작` 큰 버튼
- 부모 메뉴 잠금 아이콘

완료 조건:

- 아이가 읽지 않아도 캐릭터 음성과 한 번의 탭으로 시작 가능
- 부모 메뉴는 길게 누르기 또는 부모 확인 절차로 분리

## 3. Conversation

상태:

- `AI_SPEAKING`: 캐릭터 입 모양, 마이크 비활성
- `LISTENING`: 마이크 애니메이션과 짧은 듣기 신호
- `THINKING`: 1초 이상일 때만 작은 기다림 반응
- `CHOOSING`: 이미지 선택지 2개
- `HINT`: 짧은 한국어 의미와 동일 선택지
- `PAUSED`: 다시 시작/끝내기

아이의 화면 선택은 음성 답변을 대체할 수 있지만, 선택 직후 AI가 영어 단어를 모델링하고 부담 없는 음성 기회를 한 번 제공할 수 있다.

## 4. 의미 기반 화면 반응

| 발화 | 반응 |
|---|---|
| Pink | 대상이 분홍색으로 변함 |
| Big / Small | 대상 크기 변화 |
| Cat / Dog | 해당 동물 등장 |
| Jump | 캐릭터 점프 |
| Cookie | 쿠키 등장 |
| Happy | 캐릭터 웃음 |

반응은 0.5~1.5초이며 다음 발화를 방해하지 않는다.

## 5. Hint

단계별로 노출한다.

1. 영어 선택지 재생 + 그림
2. 한국어 의미 한 줄 + 같은 영어 선택지
3. 응답이 없으면 실패 표시 없이 다른 질문

`틀렸어`, 빨간 X, 경고음은 사용하지 않는다.

## 6. Session End

아이 화면:

- `That was fun!`
- 세션에서 만든 캐릭터 모습 또는 스티커 1개
- 다시 하기 버튼은 작게, 기본은 홈으로

발화 수나 문장 수를 아이에게 점수로 표시하지 않는다.

## 7. Parent onboarding

2분 이내:

1. 아이 표시 이름, 연령대
2. 영어 노출 경험
3. 알아볼 가능성이 있는 표현: Yes/No, I like, I want, 잘 모르겠음
4. 좋아하는 주제
5. 한국어 도움 선호
6. transcript/오디오 보관 동의 분리

첫 3회는 테스트 화면 없이 자연스러운 대화 로그로 프로필을 보정한다.

## 8. Parent report

필수 표시:

- 대화 시간
- 아이가 반응한 횟수
- 영어 또는 영어+한국어로 반응한 횟수
- 도움 없이 사용한 것으로 감지된 짧은 표현
- 오늘 자주 나온 단어
- 오늘 도움이 필요했던 표현
- 다음 세션 계획

예시:

```text
오늘 시하는 5분 18초 동안 22번 반응했어요.
영어가 들어간 대답은 15번이었어요.
“I like ___”를 도움 없이 2번 사용한 것으로 감지했어요.
다음에는 같은 표현을 놀이 속에서 다시 사용해 볼게요.
```

분류 confidence가 기준 미만이면 해당 학습 판정을 리포트에서 제외한다.

## 9. Transcript

- 기본 접힘
- AI, Child, 한국어 힌트, 시스템이 감지한 repair를 구분
- 부모가 한 세션 또는 전체 기록을 삭제 가능
- 낮은 STT confidence는 `정확하지 않을 수 있음` 표시

## 10. 접근성과 실패 상태

- 최소 터치 영역 48dp
- 자막 켜기/끄기
- 소리와 애니메이션 강도 설정
- 네트워크 오류 시 `친구가 잠깐 쉬고 있어. 다음에 또 만나자!`처럼 짧게 종료
- 로딩 중 아이 음성을 중복 제출하지 않도록 UI 잠금
